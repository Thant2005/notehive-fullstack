Project Title
-NoteHive
Goals
-Community note sharing system for university students

Tech stacks
-React(Typescript)
-Express(Typescript) or Supabase
-Postgreql(Neon DB) if use express
-Tanstack Query
-Tailwind Css
-Motion

-Functional requirements
-Authencation(signUp,signIn,signOut)
-SignIn with -Github,Google(Nice to have)
-Sidebar
-Notes listing pages
-Download File(IMG,DOCS,PDF)
-Note Upload Form
-Uplaod File With Progress Bar
-Comment Section
-Replay Comment(Nice to have)
-Preview Notes(PDF,IMG,DOCS)
-Voting(upVote,downVote)
-User Profile
-Sorted Note(Top Vote Note)
-Organize notes by semester,major,group
-Search Feature
-Filter by (Top vote,Newest vote)

Non-Functional Requirements
-Responsive Design
-Rate limiting
-Caching
